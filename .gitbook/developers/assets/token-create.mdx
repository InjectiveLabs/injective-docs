title: Creating Tokens
updatedAt: "2026-10-12"
---

The easiest way to create a token on Injective is the `tokenfactory` module, which lets any account
create a denom named `factory/{creator address}/{subdenom}` without deploying a contract. Tokens are
namespaced by creator address, so creation is permissionless.

The creator becomes the denom admin, which carries the authority to mint, burn, set metadata, and
transfer or renounce that admin role.
