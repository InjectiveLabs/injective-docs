Install `injectived` from an official release binary on Linux x86_64. For local development on another platform, use the published Docker image.

## Getting started with pre-built binaries

Download binaries for both networks from [Injective Foundation Releases](https://github.com/InjectiveFoundation/injective-core/releases). Testnet releases carry a `-beta` suffix, optionally followed by a beta number.

| Network | Release |
| --- | --- |
| Testnet | `v1.21.0-beta.2` is the latest Testnet release. |
| Mainnet | `v1.21.0` is the upcoming Mainnet release. Follow the [upgrade guide](/infra/validator-mainnet/canonical-chain-upgrade-v1.21.0) for activation. |

For a node that needs to sync now, match the active version shown on the [Mainnet Chain Portal](https://chain.injective.network) or [Testnet Chain Portal](https://chain.injective.network/testnet).

From the matching release, download `linux-amd64.zip` into a clean directory and verify it against the checksum published with the release. Extract and install the binary and the bundled Wasm runtime library:

```bash
unzip linux-amd64.zip
sudo install -m 0755 injectived /usr/bin/injectived
sudo install -m 0644 libwasmvm.x86_64.so /usr/lib/libwasmvm.x86_64.so
sudo ldconfig
injectived version
```

Verify that the output reports the version you selected. Validator operators should also install `peggo` from the same archive with `sudo install -m 0755 peggo /usr/bin/peggo`. See [Peggo Bridge](/infra/validator-mainnet/peggo) for configuration.

## Getting started with Docker

For local development, use the published Injective Core image. Replace the tag with the version required by your example.

```bash
docker run --rm injectivelabs/injective-core:v1.21.0 injectived version
```

See [Using injectived](/developers/injectived/use) for CLI commands or [Run a local native node](/developers-native/developer-setup/local-network) for local chain setup.
