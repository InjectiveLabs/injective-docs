The `Provider` oracle type allows authorized relayers to publish custom price feeds on Injective. Each price is stored under a provider name and symbol. Derivative markets and other applications can reference those feeds in their market or collateral configuration.

## Register a provider

A `GrantProviderPrivilegeProposal` specifies the provider name and the addresses authorized to relay prices. The provider and its relayers are registered when governance approves the proposal.

The CLI command's `--help` output lists the required arguments and available flags for the installed release.

```bash
injectived tx oracle grant-provider-privilege-proposal --help
```

## Relay prices

An authorized relayer submits `MsgRelayProviderPrices` with the provider name, the symbols to update, and their prices. The CLI command's `--help` output lists the accepted price format and flags.

```bash
injectived tx oracle relay-provider-prices --help
```

## Broadcast through the transaction API

Both operations can be submitted using the standard transaction service. The proposer signs the governance submission, and an authorized relayer signs a price update. The gRPC method `cosmos.tx.v1beta1.Service/BroadcastTx` accepts the encoded signed transaction and a broadcast mode.

The [Mainnet REST API](https://sentry.lcd.injective.network/swagger/) exposes the same method at `POST /cosmos/tx/v1beta1/txs`. The request takes `tx_bytes` as base64 and a `mode` such as `BROADCAST_MODE_SYNC`. That mode returns the initial transaction check. Query the returned hash for the execution result. See [Native Transactions](/developers-native/transactions/cosmos) for transaction construction and broadcasting.
