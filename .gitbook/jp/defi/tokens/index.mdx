title: トークン規格
updatedAt: "2026-10-12"

Injectiveは、dAppを作成する際に使用できるさまざまなトークン規格を提供しています。このドキュメントでは、異なるタイプのトークンと、各トークンの使用に関する推奨事項とガイダンスを説明します。

## Denom

denomは、InjectiveのBankモジュール内で資産がどのように表現されるかを示します。これらの資産は、取引、exchangeモジュールでの新しいマーケットの作成、オークションへの参加、別のアドレスへの転送などに使用できます。

denomの起源とInjectiveでの作成方法に応じて、異なるタイプのdenomがあります：

| Denomタイプ | 形式 | 起源 |
|---|---|---|
| **Native** | `inj` | Injectiveのネイティブコイン。Injective EVMのgasトークンでもあります |
| **Factory** | `factory/{creator}/{subdenom}` | [TokenFactory](/jp/defi/tokens/token-factory)を介してパーミッションレスに作成 |
| **Peggy** | `peggy0x{ERC20_CONTRACT_ADDRESS}` | [Peggyブリッジ](/jp/developers-native/bridges/ethereum)を介してEthereumからブリッジ |
| **IBC** | `ibc/{hash}` | 別のIBCチェーンからブリッジ |
| **EVM** | `erc20:0x{CONTRACT_ADDRESS}` | [Bank precompile](/jp/developers-evm/bank-precompile)に対してInjective EVM上に直接デプロイ |
| **Insurance fund** | `share{id}` | 保険基金のトークンシェア |

上記のそれぞれには登録されたbank denomがあり、ネイティブのexchange、auction、insurance、permissions
モジュールはこれを唯一の信頼できるソースとして利用します。[MultiVM Token Standard](/jp/developers-evm/multivm-token-standard)のもとでは、
トークンペアが登録されたdenomはEVMからも呼び出すことができます。[erc20モジュール](/jp/developers-evm/erc20-module)は
denomをERC20コントラクトアドレスにマッピングし、そのコントラクトへの呼び出しは
[Bank precompile](/jp/developers-evm/bank-precompile)を通じて同じbank残高に解決されます。EVM dAppは、ペアリングされた
アドレスを標準的なERC20として扱います。ブリッジや調整が必要な2つ目の残高は存在しません。

<Note>
CW20資産はネイティブのbank denomでは**ありません**。その残高はコントラクトストレージに存在します。既存のCW20は、
[CW20アダプタ](/jp/developers-cosmwasm/cw20-adapter)を通じて`factory/{CW20_ADAPTER_CONTRACT}/{CW20_CONTRACT_ADDRESS}`形式の
factory denomとして表現できますが、CW20は新規の統合には推奨されず、非推奨化が予定されています。
</Note>
