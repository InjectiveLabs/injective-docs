# RPCエンドポイント

EVM JSON-RPC、WebSocket、LCD、Tendermint RPCを含む、すべてのサービスの公開エンドポイントの最新リストは、
[Chain Portal](https://chain.injective.network/rpcs)で公開されています。Testnetの
エンドポイントとfaucetの詳細は、ポータルの[testnetページ](https://chain.injective.network/testnet)にあります。

**商用プロバイダー**（本番アプリケーションに推奨）：

- 専用キャパシティ、設定可能なレート制限、履歴データクエリのカットオフなし
- フリーミアムおよび有料オプション
- 接続方法：
    - QuickNode: [Injective RPC Node Endpoints, APIs & Tools | QuickNode](https://www.quicknode.com/chains/inj)
    - Thirdweb: [Injective EVM](https://thirdweb.com/injective)
    - Alchemy: [Alchemy RPC Setup](/developers-evm/alchemy-rpc-setup)

**公開エンドポイント**（ローカル開発や軽いテストに適しています）：

- JSON-RPCエンドポイント: `https://sentry.evm-rpc.injective.network/`
- WSエンドポイント: `wss://sentry.evm-ws.injective.network`

公開エンドポイントは共有されており、レート制限があり、履歴データクエリはカットオフされます。本番トラフィック向けの
規模ではなく、これに依存するアプリケーションは負荷時にレスポンスの欠落が発生します。トークンのローンチを計画している、
またはトラフィックの急増が見込まれるインテグレーターは、パートナーチャネルまたは[Injective Discord](https://discord.com/invite/injective)
を通じてInjectiveチームに連絡できます。パートナーのインフラプロバイダーによるローンチサポートが利用可能であり、
公開エンドポイントをローンチ計画に含めるべきではありません。

リファレンス: [EVMネットワーク情報 | Injective | Docs](/developers-evm/network-information#injective-evm-mainnet)

# ウォレット

## `injectived`

プログラマティックな制御に適しています（例：アプリケーション/dApp運用アカウント）。

インストールクイックスタート：

```shell
wget https://github.com/InjectiveLabs/injective-chain-releases/releases/download/<latest-release>/linux-amd64.zip
unzip linux-amd64.zip
sudo mv injectived peggo /usr/bin
sudo mv libwasmvm.x86_64.so /usr/lib
```

<Tip>
リリースURLはチェーンのアップグレードごとに変わります。現在のリリースは
[injective-chain-releases](https://github.com/InjectiveLabs/injective-chain-releases/releases/latest)に掲載されており、
URLを含む正確なコマンドは[Mainnet Validator](/infra/validator-mainnet)セクションにあります。チェーンが現在実行しているバージョンは
[Chain Portalのアップグレードページ](https://chain.injective.network/upgrades)に表示されています。
</Tip>

<Tip>
Dockerを使用したインストールやソースからのコンパイルなど、
その他のオプションは以下のリファレンスページで利用可能です。
</Tip>

リファレンス: [injectived | Injective | Docs](/developers/injectived)

## MetaMask

EVM DAppと連携する必要があるリテールユーザーに適しています。

インストール：

- お使いのブラウザ用のブラウザ拡張機能を[https://metamask.io/en-GB](https://metamask.io/en-GB)から取得します。
- [https://blockscout.injective.network/](https://blockscout.injective.network/)にアクセスし、ページ下部までスクロールします。
- 「Add Injective」ボタンをクリックします。
- MetaMaskのユーザーインターフェースのプロンプトに従います。

リファレンス: [Injectiveウォレットの作成方法（MetaMask）](https://injective.com/blog/how-to-create-an-injective-wallet-2/#to-connect-to-injective-with-metamask)
