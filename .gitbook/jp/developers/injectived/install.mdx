## プラットフォーム互換性ガイド

`injectived` CLIを実行できるプラットフォームを以下の表で確認してください:

| プラットフォーム | Pre-Built Binaries | Docker |
|----------|-------------------|-------- |
| macOS (M1/ARM) | ❌ | ✅ |
| macOS (Intel) | ❌ | ✅ |
| Windows (x86_64) | ❌ | ✅ |
| Windows (ARM) | ❌ | ✅ |
| Linux (x86_64) | ✅ | ✅ |
| Linux (ARM) | ❌ | ✅ |

## ビルド済みバイナリを使って始める

Linux x86_64 では [Injective Foundation Releases](https://github.com/InjectiveFoundation/injective-core/releases) からバイナリをダウンロードしてください。テストネットには `-beta` 付きのリリースを使用します。最新のテストネット版は `v1.21.0-beta.2` で、次のメインネット版は `v1.21.0` です。すぐに同期する場合はネットワークの稼働バージョンを選択し、`linux-amd64.zip` の展開前にチェックサムを確認してください。

```bash
unzip linux-amd64.zip
sudo install -m 0755 injectived /usr/bin/injectived
sudo install -m 0644 libwasmvm.x86_64.so /usr/lib/libwasmvm.x86_64.so
sudo ldconfig
injectived version
```

`injectived version` を実行し、選択したリリースと一致することを確認してください。バリデーターは対応するバージョンの Peggo もインストールしてください。

## Dockerを使って始める

ローカル開発には公開 Docker イメージも使用できます。例で指定されているバージョンのタグを選んでください。

```bash
docker run --rm injectivelabs/injective-core:v1.21.0 injectived version
```
