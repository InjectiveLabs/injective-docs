## Injectiveとは？

Injectiveは**金融**のために構築された**ブロックチェーン**です。

## Injectiveの何が違うのか？

Injectiveは、完全オンチェーンのオーダーブック取引所、
Frequent Batch Auction（FBA）によるMEV耐性のあるトランザクション順序付け、
110以上のIBCネットワークおよびEthereumとのクロスチェーン相互運用性、
EVMスマートコントラクト、
そして生成AIとエージェント型ビルダーツールを提供します。

Injectiveは、開発者が他のネットワークでは不可能な動的アプリケーションを作成するために、事前構築されたカスタマイズ可能な[モジュール](./developers-native/)を使用できる唯一のブロックチェーンです。コアアーキテクチャの最適化と強化されたクロスチェーン相互運用性を組み合わせることで、Injectiveはグローバル金融システムを効率的かつ安全にオンチェーン化するための高性能ネットワークを提供します。

## Injectiveのパフォーマンスは？

Injectiveは非常に高いスケーラビリティも備えています：

  |  |  |
  |---|---|
  | スループット（持続） | 25,000 tx/s |
  | スループット（理論上の上限） | 600,000 tx/s |
  | ブロックタイム | 650ms |
  | トランザクションファイナリティ | 即時（カスタムTendermint（CometBFT）による） |
  | 標準的なトランザクション手数料 | 約 $0.0003 |
  | 平均トランザクション手数料 | $0.01未満 |

<Info>
  上記の統計値は2026年4月時点のものです。
  市場の動向や利用状況によって変動する可能性があることにご注意ください。
</Info>
