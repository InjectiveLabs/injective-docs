## すべてのインテグレーターが得られるもの

| 機能 | 意味するところ |
|---|---|
| **MultiVM Token Standard** | EVMとNative Injectiveをまたいで1つのトークン、1つの残高。ラッピング不要。 |
| **ネイティブCLOB** | FBAを備えたオンチェーンorderbook。1トランザクションでspotマーケットをローンチ。 |
| **サブ秒ファイナリティ** | 約0.65秒のブロックタイムと即時ファイナリティ。 |
| **USDC流動性** | CircleのCCTPによるネイティブUSDC。すでに稼働中。 |
| **40%の手数料シェア** | エクスチェンジdAppは、自身が起点となった注文の取引手数料の40%を獲得。 |
| **テストネット + faucet** | INJおよびUSDCのfaucet、EVMとネイティブのエクスプローラーを備えた完全なテストネット。 |
