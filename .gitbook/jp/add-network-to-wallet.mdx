ワンクリックで Injective をブラウザウォレットに追加するか、以下の手動設定の詳細を使用してください。Injective は相互運用可能な 2 つのインターフェースを提供しています：

- **Injective EVM** は Ethereum 互換の JSON-RPC レイヤーです。MetaMask や Trust Wallet などの EVM ウォレットで使用します。
- **Injective（ネイティブ）** はネイティブの Cosmos SDK チェーンです。Keplr で使用します。

<Info>
Injective EVM と Injective ネイティブは同じネットワークに対応しています。異なる chain ID を使用しますが、同じ基盤となるステートを共有しています。完全なリファレンスについては
[ネットワーク情報](/jp/developers/network-information) と
[EVM ネットワーク情報](/jp/developers-evm/network-information) を参照してください。
</Info>

## Injective EVM
