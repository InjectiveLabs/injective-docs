Injective의 자산은 bank 모듈에서 denom으로 표현됩니다. denom이 작동하는 방식을 이해하는 것은 체인의 토큰과 상호작용하는 애플리케이션을 구축하는 데 필수적입니다.

<Callout icon="info" color="#22C55E" iconType="regular">
**토큰 메타데이터를 찾고 계신가요?** [Injective List](./injective-list) 저장소는 여러 소스의 온체인 denom 메타데이터를 하나의 포괄적인 마스터 목록으로 집계합니다. 애플리케이션에서 denom 정보를 조회하는 데 권장되는 방법입니다.
</Callout>

## 이 섹션의 내용

- [**Denom**](./denom) - 자산이 온체인에서 표현되는 방식 (네이티브, peggy, IBC, factory denom)
- [**Injective List**](./injective-list) - 표준 토큰 메타데이터 레지스트리와 통합 방법
- [**토큰 메타데이터**](./token-metadata) - denom에 사람이 읽을 수 있는 메타데이터 연결하기
- [**토큰 생성**](./token-create) - Token Factory 모듈을 사용하여 새 토큰 생성하기
