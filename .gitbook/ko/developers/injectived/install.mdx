## 플랫폼 호환성 가이드

`injectived` CLI를 실행하기 위해 지원되는 플랫폼을 확인하려면 이 표를 참조하세요:

| 플랫폼 | 사전 빌드 바이너리 | Docker |
|----------|-------------------|-------- |
| macOS (M1/ARM) | ❌ | ✅ |
| macOS (Intel) | ❌ | ✅ |
| Windows (x86_64) | ❌ | ✅ |
| Windows (ARM) | ❌ | ✅ |
| Linux (x86_64) | ✅ | ✅ |
| Linux (ARM) | ❌ | ✅ |

## 사전 빌드 바이너리로 시작하기

Linux x86_64에서는 [Injective Foundation Releases](https://github.com/InjectiveFoundation/injective-core/releases)에서 바이너리를 다운로드하세요. 테스트넷은 `-beta` 릴리스를 사용하며 최신 버전은 `v1.21.0-beta.2`입니다. 다음 메인넷 릴리스는 `v1.21.0`입니다. 지금 동기화하려면 네트워크에서 실행 중인 버전을 선택하고 `linux-amd64.zip`의 체크섬을 확인한 후 압축을 푸세요.

```bash
unzip linux-amd64.zip
sudo install -m 0755 injectived /usr/bin/injectived
sudo install -m 0644 libwasmvm.x86_64.so /usr/lib/libwasmvm.x86_64.so
sudo ldconfig
injectived version
```

`injectived version`을 실행해 선택한 릴리스와 일치하는지 확인하세요. 검증자는 동일한 버전의 Peggo도 설치해야 합니다.

## Docker로 시작하기

로컬 개발에는 공개 Docker 이미지도 사용할 수 있습니다. 예제에서 사용하는 버전 태그를 선택하세요.

```bash
docker run --rm injectivelabs/injective-core:v1.21.0 injectived version
```
