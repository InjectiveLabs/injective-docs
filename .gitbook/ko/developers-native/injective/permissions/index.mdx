## 할 수 있는 것

Permissions 모듈은 Injective의 모든 토큰에 대해 네이티브 체인 레벨 접근 제어를 제공합니다. 기관, 은행, 규제 대상 기업이 커스텀 스마트 컨트랙트 인프라를 배포하지 않고도 컴플라이언스가 내장된 자산을 발행할 수 있게 합니다.

### 지원되는 행위

| 행위 | 제어 대상 |
|---|---|
| **MINT** | 새로운 토큰 공급량 생성 |
| **BURN** | 보유자 자신의 주소에서 토큰 소각 |
| **SEND** | 다른 주소로 토큰 전송 |
| **RECEIVE** | 들어오는 토큰 전송 수락 |
| **SUPER_BURN** | 모든 주소의 토큰 소각(규제 압류) |

### 역할이 실제 사용 사례에 매핑되는 방식

| 사용 사례 | 역할 | 권한 |
|---|---|---|
| 발행 은행 | 토큰 관리자 | MINT, BURN |
| 회원 은행 / 검증된 보유자 | 화이트리스트에 등록된 참여자 | SEND, RECEIVE |
| 컴플라이언스 관리자 | 규제 당국 | SUPER_BURN |
| 컨소시엄 거버넌스 | 정책 관리자 | 역할 수정, 권한 수정, 행위 일시 중지 |
| KYC/AML 시행 | 컨트랙트 훅 | 실행 전에 모든 전송을 컴플라이언스 규칙에 따라 검증 |
| 리테일 / 일반 | EVERYONE(기본값) | 권한 없음(보유하거나 거래할 수 없음) |

### 컨트랙트 훅

이 모듈은 모든 전송 시 호출되는 Solidity 또는 WasmVM 훅을 지원합니다. 이를 통해 AML 임계값 확인, KYC 검증, 제재 대상 스크리닝, 은행 간 전송 제한 같은 커스텀 컴플라이언스 로직을 구현할 수 있습니다. Circle은 Injective에서의 USDC 컴플라이언스에 이 패턴을 사용합니다([참조 구현](https://github.com/InjectiveLabs/stablecoin-evm/blob/fiattoken-inj/contracts/v2/PermissionsHook_Inj.sol)).
