Injective는 프로토콜 레이어에 직접 내장된 매칭 엔진 기능을 갖춘 완전한 온체인 오더북을 제공합니다. Injective에서 구축된 거래소는 자체 UI와 사용자 관계를 유지하면서 전역 통합 유동성 풀을 공유하며, 자신이 발생시킨 주문의 거래 수수료 중 40%를 받습니다.

현물, 무기한 스왑, 선물 및 무허가형 마켓 생성을 1초 미만의 블록 타임으로 네이티브 지원합니다. 구축해야 할 백엔드 인프라도, 유동성 파편화도 없습니다.

## 핵심 개념

| 용어 | 설명 |
|------|-------------|
| **Exchange 모듈** | 오더북 관리, 거래 실행, 주문 매칭, 정산을 처리하는 네이티브 온체인 모듈. [전체 참조](/ko/developers-native/injective/exchange) |
| **FBA (Frequent Batch Auction)** | 블록 내의 모든 주문이 블록 종료 시 단일 청산 가격으로 매칭됩니다. 프론트러닝을 제거합니다. |
| **40% 수수료 분배** | 주문을 발생시킨 거래소는 거래 수수료의 40%를 받습니다. 나머지 60%는 커뮤니티 소각/바이백에 사용됩니다. |
| **틱 사이즈** | 거래 마켓에서 가격과 수량의 최소 증가 단위. [가격 틱 계산기](/ko/developers-defi/calculate-min-price-tick-size)와 [수량 틱 계산기](/ko/developers-defi/min-quantity-tick-size)를 참조하세요. |
| **Token Factory** | `factory/{creator}/{subdenom}` 형식의 무허가형 토큰 생성을 위한 네이티브 모듈. |
| **서브계정** | 메인 지갑과 분리된, 마진 및 포지션 관리를 위한 격리된 [트레이딩 계정](/ko/developers/concepts/trading-account). |
