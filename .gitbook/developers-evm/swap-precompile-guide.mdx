Use Injective’s Swap Precompile from TypeScript to quote and execute spot swaps against the native order book. This guide covers the call parameters, token units, slippage protection, deadlines, simulation, transaction submission, and settlement.

The worked example uses INJ and Circle USDC on testnet. Its network, token addresses, and market ID are example configuration. The precompile workflow also applies to other active, allowlisted markets with supported token directions, including on mainnet.

## Call the Swap Precompile

The Swap Precompile exposes Injective’s native spot exchange through the EVM at `0x0000000000000000000000000000000000000068`. Each call supplies a market ID, a token address, and an amount. The market ID selects the order book; the interface supports active, allowlisted markets and the token directions enabled on the chosen network.

1. Select a network and a supported spot market.
2. Resolve the input token and express the amount in its native integer units.
3. Read a quote, then derive a minimum output and a deadline.
4. Simulate the swap from the funded caller, submit it, and wait for a successful receipt.

The TypeScript example below follows this workflow with INJ and USDC. The same call pattern applies when integrating another supported pair.

## Understand the example call

The precompile converts an EVM call into an atomic spot market order in Injective’s exchange module. For the INJ/USDC worked example, the input token determines the direction:

| Action   | Input token               | Input amount         | Output      |
| -------- | ------------------------- | -------------------- | ----------- |
| Buy INJ  | Market USDC ERC20 address | USDC with 6 decimals | Native INJ  |
| Sell INJ | `zeroAddress`             | INJ with 18 decimals | Market USDC |

`marketId` is an ABI `string`, even though it contains a 32-byte hash. Amounts are integer token units. `parseUnits('10', 6)` represents 10 USDC; `parseUnits('0.1', 18)` represents 0.1 INJ. Use decimal strings and bigint throughout.

For a direct EOA call, the precompile debits the caller’s existing bank balance. Circle USDC exposes that same balance through the MultiVM Token Standard. Its native bank denom is derived automatically as `erc20:<checksummed token address>`; no stored token-pair registration is required. No ERC20 allowance to `0x68` is needed. Omit transaction `value`, including when selling INJ: a nonzero value reverts. INJ is still required to pay transaction gas when buying it.

The V2 methods return both `amountInSpent` and `amountOut`. `amountIn` is the input budget; thin liquidity or quantity ticks can leave part of it unspent. `minOut` protects the absolute output of the fill. It does not enforce that the whole input budget was consumed. Show the quoted spent amount to the user alongside the expected output.

A failed output check reverts the swap’s state changes; transaction gas can still be charged. Quotes describe the current book, and execution can differ because orders and account-specific fee discounts change. The execution-time minimum output and deadline are the binding constraints.

## Resolve the example token

For the worked example, the input token determines whether the call buys INJ with USDC or sells INJ for USDC. Token resolution must agree with the selected market’s base and quote denoms.

Query the denom resolution without listing all token pairs:

```bash
curl --get 'https://k8s.testnet.lcd.injective.network/injective/erc20/v1beta1/token_pair_by_erc20_address' \
  --data-urlencode 'erc20_address=0x0C382e685bbeeFE5d3d9C29e29E341fEE8E84C5d'
```

The response associates the ERC20 address with `erc20:0x0C382e685bbeeFE5d3d9C29e29E341fEE8E84C5d`. For EVM-native MTS tokens, this query can derive the relationship without a stored pair. Native TokenFactory denoms follow a different registration path; see the [ERC20 module reference](/developers-evm/erc20-module).

Fund a dedicated testnet EVM account with INJ from the [Injective faucet](https://testnet.faucet.injective.network/) and USDC from [Circle’s faucet](https://faucet.circle.com/). For buys, the book needs resting INJ sell orders; for sells, it needs resting buy orders funded with this USDC. A successful sell quote alone does not establish buy-side liquidity. Testnet order-book prices can be arbitrary; do not interpret the tutorial market as a reference for INJ’s real price.

## Define the network and ABI

Save as `src/config.ts`. The small ABI includes V1 for diagnostics and V2 for swaps that report actual input consumption.

```typescript
import { http, parseAbi, defineChain, createPublicClient } from 'viem'

export const RPC_URL =
  process.env.RPC_URL ?? 'https://k8s.testnet.json-rpc.injective.network/'
export const LCD_URL = (
  process.env.LCD_URL ?? 'https://k8s.testnet.lcd.injective.network'
).replace(/\/$/, '')
export const MARKET_ID =
  process.env.MARKET_ID ??
  '0x0f6ee483a7f7f633fe6e3f03d34e01e129b5a5023eb7b0fe1e8a56e5ac8779a6'
export const SWAP = '0x0000000000000000000000000000000000000068' as const
export const USDC_ADDRESS =
  '0x0C382e685bbeeFE5d3d9C29e29E341fEE8E84C5d' as const
export const USDC_DENOM = `erc20:${USDC_ADDRESS}`

export const chain = defineChain({
  id: 1439,
  name: 'Injective EVM Testnet',
  nativeCurrency: { name: 'Injective', symbol: 'INJ', decimals: 18 },
  rpcUrls: { default: { http: [RPC_URL] } },
  blockExplorers: {
    default: {
      name: 'Blockscout',
      url: 'https://testnet.blockscout.injective.network'
    }
  },
  testnet: true
})
export const client = createPublicClient({ chain, transport: http(RPC_URL) })
export const swapAbi = parseAbi([
  'function quoteExactInputV1(address tokenIn, string marketId, uint256 amountIn) view returns (uint256 amountOut)',
  'function quoteExactInputV2(address tokenIn, string marketId, uint256 amountIn) view returns (uint256 amountInSpent, uint256 amountOut)',
  'function swapExactInputV2(address tokenIn, string marketId, uint256 amountIn, uint256 minOut, address recipient, uint256 deadline) returns (uint256 amountInSpent, uint256 amountOut)'
])
export const tokenAbi = parseAbi([
  'function decimals() view returns (uint8)',
  'function balanceOf(address owner) view returns (uint256)'
])

export type Market = {
  ticker: string
  status: string
  market_id: string
  base_denom: string
  quote_denom: string
  min_notional: string
  base_decimals: number
  quote_decimals: number
  min_quantity_tick_size: string
}
export type SwapParams = { enabled: boolean; allowed_markets: string[] }
export type TokenPair = { bank_denom: string; erc20_address: string }

export async function lcd<T>(path: string): Promise<T> {
  const response = await fetch(`${LCD_URL}${path}`, {
    signal: AbortSignal.timeout(20_000)
  })
  if (!response.ok)
    throw new Error(`LCD ${response.status}: ${await response.text()}`)

  return (await response.json()) as T
}

export async function inspect() {
  if (!/^0x[0-9a-fA-F]{64}$/.test(MARKET_ID))
    throw new Error('MARKET_ID must be a 0x-prefixed 32-byte hash string')
  const [chainId, node, params, market, pair] = await Promise.all([
    client.getChainId(),
    lcd<{ default_node_info: { network: string } }>(
      '/cosmos/base/tendermint/v1beta1/node_info'
    ),
    lcd<{ params: { swap_params: SwapParams; exchange_admins: string[] } }>(
      '/injective/exchange/v2/exchangeParams'
    ),
    lcd<{ market: null | Market }>(
      `/injective/exchange/v2/spot/markets/${MARKET_ID}`
    ),
    lcd<{ token_pair: null | TokenPair }>(
      `/injective/erc20/v1beta1/token_pair_by_denom?bank_denom=${encodeURIComponent(USDC_DENOM)}`
    )
  ])
  if (chainId !== 1439 || node.default_node_info.network !== 'injective-888') {
    throw new Error(
      'RPC and LCD must both target Injective testnet (1439 / injective-888)'
    )
  }

  return {
    chainId,
    nativeChainId: node.default_node_info.network,
    swap_params: params.params.swap_params,
    exchange_admins: params.params.exchange_admins,
    market: market.market,
    tokenPair: pair.token_pair
  }
}
```

## Implement quote simulation and execution

Save as `src/swap.ts`. The default mode reads a quote. `--simulate` checks execution using the specified account without submitting a transaction. `--send` signs and broadcasts a real testnet transaction.

```typescript
import { privateKeyToAccount } from 'viem/accounts'
import {
  http,
  getAddress,
  parseUnits,
  formatUnits,
  zeroAddress,
  createWalletClient
} from 'viem'
import {
  SWAP,
  chain,
  client,
  inspect,
  swapAbi,
  tokenAbi,
  MARKET_ID,
  USDC_DENOM,
  USDC_ADDRESS
} from './config.js'

async function main() {
  const [side, amount, mode = '--quote'] = process.argv.slice(2)

  if (
    !['buy', 'sell'].includes(side) ||
    !amount ||
    !['--send', '--quote', '--simulate'].includes(mode)
  ) {
    throw new Error(
      'Usage: npm run swap -- buy|sell AMOUNT [--quote|--simulate|--send]'
    )
  }

  const state = await inspect()
  const market = state.market

  if (
    !market ||
    market.status !== 'Active' ||
    market.base_denom !== 'inj' ||
    market.quote_denom !== USDC_DENOM
  ) {
    throw new Error(
      'Expected the active INJ / Circle USDC testnet market; do not select a market by ticker alone.'
    )
  }

  if (
    !state.swap_params.enabled ||
    !state.swap_params.allowed_markets.some(
      (id) => id.toLowerCase() === MARKET_ID.toLowerCase()
    )
  ) {
    throw new Error(
      'Swaps disabled or this market is not allowlisted. An exchange admin must update SwapParams.'
    )
  }
  if (!state.tokenPair) {
    throw new Error(
      'Circle USDC bank denom could not be resolved on this network'
    )
  }

  const usdc = getAddress(state.tokenPair.erc20_address)

  if (usdc !== getAddress(USDC_ADDRESS)) {
    throw new Error('Resolved token is not the expected Circle USDC deployment')
  }

  const decimals = await client.readContract({
    address: usdc,
    abi: tokenAbi,
    functionName: 'decimals'
  })

  if (
    decimals !== 6 ||
    Number(market.quote_decimals) !== 6 ||
    Number(market.base_decimals) !== 18
  ) {
    throw new Error('Unexpected token or market decimals')
  }

  const buying = side === 'buy'
  const tokenIn = buying ? usdc : zeroAddress
  const inputDecimals = buying ? 6 : 18
  const outputDecimals = buying ? 18 : 6
  const inputSymbol = buying ? 'USDC' : 'INJ'
  const outputSymbol = buying ? 'INJ' : 'USDC'

  // Reject excess precision instead of silently rounding user input.
  if (
    !/^\d+(\.\d+)?$/.test(amount) ||
    (amount.split('.')[1]?.length ?? 0) > inputDecimals
  ) {
    throw new Error(
      `AMOUNT must be a positive decimal string with at most ${inputDecimals} fractional digits`
    )
  }

  const amountIn = parseUnits(amount, inputDecimals)

  if (amountIn <= 0n) {
    throw new Error('AMOUNT must be positive')
  }

  const bps = Number(process.env.SLIPPAGE_BPS ?? '50')

  if (!Number.isInteger(bps) || bps < 0 || bps >= 10_000) {
    throw new Error('SLIPPAGE_BPS must be an integer from 0 to 9999')
  }

  const [quotedSpent, quotedOut] = await client.readContract({
    address: SWAP,
    abi: swapAbi,
    functionName: 'quoteExactInputV2',
    args: [tokenIn, MARKET_ID, amountIn]
  })

  const minOut = (quotedOut * BigInt(10_000 - bps)) / 10_000n

  if (quotedSpent <= 0n || quotedOut <= 0n || minOut <= 0n) {
    throw new Error('Quote is too small for a protected swap')
  }

  console.log({
    inputBudget: `${formatUnits(amountIn, inputDecimals)} ${inputSymbol}`,
    estimatedInputSpent: `${formatUnits(quotedSpent, inputDecimals)} ${inputSymbol}`,
    estimatedOutput: `${formatUnits(quotedOut, outputDecimals)} ${outputSymbol}`,
    minimumOutput: `${formatUnits(minOut, outputDecimals)} ${outputSymbol}`
  })

  if (mode === '--quote') {
    return
  }

  const privateKey = process.env.PRIVATE_KEY

  if (!privateKey || !/^0x[0-9a-fA-F]{64}$/.test(privateKey)) {
    throw new Error(
      'Set PRIVATE_KEY to a dedicated testnet account key in your local .env'
    )
  }

  const account = privateKeyToAccount(privateKey as `0x${string}`)
  const wallet = createWalletClient({
    chain,
    account,
    transport: http(chain.rpcUrls.default.http[0])
  })

  const block = await client.getBlock()
  const deadline = block.timestamp + 120n
  const args = [
    tokenIn,
    MARKET_ID,
    amountIn,
    minOut,
    account.address,
    deadline
  ] as const

  const call = {
    address: SWAP,
    abi: swapAbi,
    functionName: 'swapExactInputV2' as const,
    args,
    account
  }

  const [injBefore, usdcBefore] = await Promise.all([
    client.getBalance({ address: account.address, blockNumber: block.number }),
    client.readContract({
      address: usdc,
      abi: tokenAbi,
      functionName: 'balanceOf',
      args: [account.address],
      blockNumber: block.number
    })
  ])
  if ((buying ? usdcBefore : injBefore) < amountIn) {
    throw new Error('Insufficient input balance for the full input budget')
  }

  const { result } = await client.simulateContract(call)
  const estimate = await client.estimateContractGas(call)
  const gas = (estimate * 120n + 99n) / 100n
  const gasPrice = await client.getGasPrice()

  if (injBefore < gas * gasPrice + (buying ? 0n : amountIn)) {
    throw new Error('Keep enough INJ for the input budget plus gas')
  }

  console.log('Simulation only:', {
    estimatedInputSpent: result[0].toString(),
    estimatedOutput: result[1].toString(),
    gasLimit: gas.toString()
  })

  if (mode === '--simulate') {
    return
  }

  // No value: the precompile debits the caller's existing bank/MTS balance.
  const hash = await wallet.writeContract({
    ...call,
    gas,
    gasPrice,
    type: 'legacy'
  })

  console.log('Submitted:', `${chain.blockExplorers.default.url}/tx/${hash}`)

  const receipt = await client.waitForTransactionReceipt({ hash })

  if (receipt.status !== 'success') {
    throw new Error(`Swap reverted: ${hash}`)
  }

  const [injAfter, usdcAfter] = await Promise.all([
    client.getBalance({
      address: account.address,
      blockNumber: receipt.blockNumber
    }),
    client.readContract({
      address: usdc,
      abi: tokenAbi,
      functionName: 'balanceOf',
      args: [account.address],
      blockNumber: receipt.blockNumber
    })
  ])

  const gasPaid = receipt.gasUsed * receipt.effectiveGasPrice

  console.log('Confirmed balance changes:', {
    INJ: formatUnits(injAfter - injBefore, 18),
    USDC: formatUnits(usdcAfter - usdcBefore, 6),
    gasPaidINJ: formatUnits(gasPaid, 18),
    INJExcludingGas: formatUnits(injAfter - injBefore + gasPaid, 18)
  })
}

main().catch((error) => {
  console.error(error instanceof Error ? error.message : String(error))
  process.exitCode = 1
})
```

## Run the example swaps

First request quotes. The amount after `buy` is a USDC budget; the amount after `sell` is an INJ budget:

```bash
npm run swap -- buy 10
npm run swap -- sell 0.1
```

With a dedicated testnet key set locally, simulate each direction:

```bash
npm run swap -- buy 10 --simulate
npm run swap -- sell 0.1 --simulate
```

Broadcast only the intended trade:

```bash
npm run swap -- buy 10 --send
npm run swap -- sell 0.1 --send
```

These are separate trades, each with its own quote, slippage check, transaction fee, and book impact. Selling after a buy does not guarantee recovery of the original USDC budget.

At the illustrative testnet prices of a 0.99 USDC bid and 1.01 USDC ask, the following V2 quotes show how the input budget and actual spend differ. These values are a worked example; request a fresh quote before each trade.

| Direction | Input budget | Quoted input spent | Quoted output |
| --------- | ------------ | ------------------ | ------------- |
| Buy INJ   | 10 USDC      | 9.999977 USDC      | 9.8891 INJ    |
| Sell INJ  | 0.1 INJ      | 0.1 INJ            | 0.098881 USDC |

The buy leaves 0.000023 USDC unspent because of quantity-tick rounding. Transaction gas is paid separately in INJ.

The example uses 50 basis points, or 0.5 percent, as an illustrative output tolerance. It computes `minOut = quotedOut * 9950 / 10000` with bigint division. Choose the tolerance deliberately for your application. A minimum output derived from an off-chain quote allows the fill to deteriorate within that bound before inclusion.

The deadline is the latest block timestamp plus 120 seconds. It uses seconds, not JavaScript milliseconds. The example estimates gas against the actual call and adds 20 percent to the estimate. This buffer is an example policy, not a fixed gas requirement; gas estimates can still become stale.

## Read the result correctly

`simulateContract` returns estimated contract return values. [`writeContract`](https://viem.sh/docs/contract/writeContract) returns a transaction hash; a receipt does not contain the function’s Solidity return values. Wait for a successful receipt before reporting completion.

The script reads INJ and USDC balances at the block before submission and at the receipt’s block. It reports the INJ delta both including and excluding the transaction’s gas cost. These deltas attribute the trade cleanly only when the account has no other activity during that interval. Settlement can also carry sub-unit dust in the default subaccount, making a raw bank-balance movement differ from a rounded swap amount by one smallest unit.

For an application, persist the transaction hash, recipient, market ID, input budget, minimum output, deadline, and confirmed status. Use decoded native exchange events or carefully attributed balance changes for the executed amounts. Label simulation results as estimates.

## Use another market or mainnet

Choose the target network, then read its active spot markets and swap allowlist. Check the exact base and quote denoms, token addresses, decimals, quantity tick, and minimum notional. Use an ABI version and swap direction supported by the deployed precompile.

| Network | EVM chain ID | Native chain ID | EVM RPC                                           |
| ------- | ------------ | --------------- | ------------------------------------------------- |
| Mainnet | `1776`       | `injective-1`   | `https://sentry.evm-rpc.injective.network/`       |
| Testnet | `1439`       | `injective-888` | `https://k8s.testnet.json-rpc.injective.network/` |

These settings are listed in the [EVM network reference](/developers-evm/network-information). Token addresses and market IDs must come from the selected network.

When adapting the bundled sample, update the chain definition, RPC and REST endpoints, expected native chain ID, market ID, token addresses, and decimal checks together. For a different pair, also replace the INJ/USDC input selection, display labels, and balance accounting. The sample’s explicit validation targets its testnet example; changing only `MARKET_ID` or `RPC_URL` does not adapt those checks.

The quote, minimum-output calculation, deadline, simulation, and receipt workflow stays the same. An input token matching the market’s base asset sells base for quote; an input token matching its quote asset buys base. Native INJ uses the zero address. Other supported assets use their ERC20 address.

Swaps require available opposing orders, an active allowlisted market, and a supported route. Check the destination network’s current [Swap Precompile reference](/developers-evm/swap-precompile) and live configuration before submitting.

## Troubleshoot a failed call

| Symptom                                 | Action                                                                                                                 |
| --------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Market is not allowlisted               | Re-query swap parameters; use an authorized exchange admin to add it while preserving existing entries.                |
| Circle USDC cannot be resolved          | Confirm the RPC network and token address. EVM-native MTS USDC needs no manual token-pair registration.                |
| Input denom matches neither market side | Compare the resolved ERC20 bank denom with the actual market base and quote denoms. A matching ticker is insufficient. |
| No liquidity                            | Inspect the opposing side of the order book and reduce the requested size or seed test liquidity.                      |
| Amount or notional too small            | Respect the market’s quantity tick and minimum notional. A tiny input can round to zero.                               |
| Output below minimum                    | Obtain a new quote; inspect book changes and tolerance before retrying.                                                |
| Deadline passed                         | Refresh the quote and use a new deadline based on chain time.                                                          |
| Insufficient funds                      | Fund the full input budget and keep INJ for gas.                                                                       |
| Value transfer rejected                 | Remove `value` from the precompile call.                                                                               |
| Unknown V2 method                       | Check the deployed node version; do not decode a V1 response as V2.                                                    |
| Quote succeeds but execution fails      | Simulate from the real sender; check balances, post-only mode, token restrictions, and available gas.                  |

## API alternatives

V1 exact-input methods return only output. V2 exposes spent input as well and is the focus of this guide. `quoteExactOutputV1` and `swapExactOutputV1` take the output token: they can express a target such as receiving at least a chosen INJ amount for a capped USDC input. Tick rounding can deliver slightly more than the target. Check support on the deployed node before adopting those methods.

The V1 and V2 suffixes on these ABI methods are API versions. They are separate from the exchange module’s legacy v1beta1 and current v2 protobuf types.
