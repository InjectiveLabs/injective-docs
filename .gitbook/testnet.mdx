Injective Testnet is a staging network for validating integrations before mainnet. It runs the native chain and EVM, so you can test transactions, contracts, and upcoming releases on the same network.

| Interface | Chain ID |
| --- | --- |
| Native | `injective-888` |
| EVM | `1439` |

The latest Testnet binary is `v1.21.0-beta.2`. Download Testnet `-beta` binaries from [Injective Foundation Releases](https://github.com/InjectiveFoundation/injective-core/releases).
