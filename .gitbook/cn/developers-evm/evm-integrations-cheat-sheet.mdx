# RPC Endpoints

所有服务的公共 endpoint 维护列表，包括 EVM JSON-RPC、WebSocket、LCD 和
Tendermint RPC，均发布在 [Chain Portal](https://chain.injective.network/rpcs) 上。测试网
endpoint 和水龙头详情请参阅门户的[测试网页面](https://chain.injective.network/testnet)。

**商业提供商**，推荐用于生产应用：

- 专用容量、可配置的速率限制，历史数据查询无截止
- 免费增值和付费选项
- 如何连接：
    - QuickNode: [Injective RPC Node Endpoints, APIs & Tools | QuickNode](https://www.quicknode.com/chains/inj)
    - Thirdweb: [Injective EVM](https://thirdweb.com/injective)
    - Alchemy: [Alchemy RPC 设置](/cn/developers-evm/alchemy-rpc-setup)

**公共 endpoint**，适用于本地开发和轻量测试：

- JSON-RPC Endpoint: `https://sentry.evm-rpc.injective.network/`
- WS Endpoint: `wss://sentry.evm-ws.injective.network`

公共 endpoint 是共享的且有速率限制，历史数据查询有截止。它们并非
为生产流量而设计，依赖它们的应用在高负载下会出现响应丢失。计划发行 token
或预期流量激增的集成方，可以通过合作伙伴渠道或 [Injective Discord](https://discord.com/invite/injective)
联系 Injective 团队：我们可以协调合作的基础设施提供商提供发行支持，公共 endpoint 不应
成为发行计划的一部分。

参考: [EVM 网络信息 | Injective | Docs](/cn/developers-evm/network-information#injective-evm-mainnet)

# 钱包

## `injectived`

适用于程序化控制，例如应用/dApp 操作的账户。

安装快速入门：

```shell
wget https://github.com/InjectiveLabs/injective-chain-releases/releases/download/<latest-release>/linux-amd64.zip
unzip linux-amd64.zip
sudo mv injectived peggo /usr/bin
sudo mv libwasmvm.x86_64.so /usr/lib
```

<Tip>
发布 URL 会随每次链升级而变化。当前版本列在
[injective-chain-releases](https://github.com/InjectiveLabs/injective-chain-releases/releases/latest)，
确切的命令（包括 URL）位于
[Mainnet Validator](/cn/infra/validator-mainnet) 部分。链当前运行的版本显示在
[Chain Portal 升级页面](https://chain.injective.network/upgrades)上。
</Tip>

<Tip>
更多选项，包括通过 Docker 安装或从源代码编译，
可在下面的参考页面中找到。
</Tip>

参考: [injectived | Injective | Docs](/cn/developers/injectived) 

## MetaMask

适用于需要与 EVM DApp 交互的零售用户。

安装：

- 从 [https://metamask.io/en-GB](https://metamask.io/en-GB) 获取适用于你特定浏览器的浏览器扩展。
- 访问 [https://blockscout.injective.network/](https://blockscout.injective.network/)，滚动到页面底部
- 点击 "Add Injective" 按钮
- 按照 MetaMask 用户界面中的提示操作

参考: [如何创建 Injective 钱包 (MetaMask)](https://injective.com/blog/how-to-create-an-injective-wallet-2/#to-connect-to-injective-with-metamask)
