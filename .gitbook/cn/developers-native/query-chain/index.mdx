本节介绍如何直接从 Injective 区块链查询数据。

## Protobuf 定义 {#protobuf-definitions}

使用 [Injective Protobuf 定义](https://github.com/InjectiveLabs/injective-proto/tree/master/all_protos)进行原生模块查询、交易消息和 indexer 服务。该[仓库](https://github.com/InjectiveLabs/injective-proto)还提供了 C++、C#、Java、Python 和 Rust 的生成绑定。客户端库请参阅 [SDKs](/cn/sdks-index)，服务地址请参阅[主网](/cn/infra/public-endpoints)或[测试网](/cn/testnet/public-endpoints)公共端点。
