## 每个集成方都能获得什么

| 能力 | 含义 |
|---|---|
| **MultiVM 代币标准** | 一份代币、一个余额，通用于 EVM 和原生 Injective。无需封装。 |
| **原生 CLOB** | 带 FBA 的链上订单簿。一笔交易即可发行现货市场。 |
| **亚秒级最终性** | 约 0.65 秒出块时间，即时最终性。 |
| **USDC 流动性** | 通过 Circle 的 CCTP 提供原生 USDC。已经上线。 |
| **40% 费用分成** | 交易所 dApp 可从其发起的订单中赚取 40% 的交易费用。 |
| **测试网 + 水龙头** | 完整的测试网，提供 INJ 和 USDC 水龙头、EVM 和原生浏览器。 |
