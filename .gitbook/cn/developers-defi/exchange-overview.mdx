Injective 提供完全链上的订单簿，撮合引擎能力直接内置于协议层。基于 Injective 构建的交易所共享一个全局统一的流动性池，同时保有各自的 UI 和用户关系，并从其发起的订单中赚取 40% 的交易手续费。

原生支持现货、永续合约、期货以及无需许可的市场创建，出块时间不到一秒。无需构建后端基础设施，也不存在流动性碎片化。

## 关键概念 {#key-concepts}

| 术语 | 说明 |
|------|-------------|
| **Exchange Module** | 原生链上模块，负责订单簿管理、交易执行、订单撮合和结算。[完整参考](/developers-native/injective/exchange) |
| **FBA（频繁批量拍卖）** | 一个区块中的所有订单在区块结束时以单一清算价格撮合，从而消除抢先交易。 |
| **40% 手续费分成** | 发起订单的交易所可赚取 40% 的交易手续费，其余 60% 用于社区销毁/回购。 |
| **Tick Size** | 交易市场中价格和数量的最小增量。请参阅[价格 tick 计算器](/cn/developers-defi/calculate-min-price-tick-size)和[数量 tick 计算器](/cn/developers-defi/min-quantity-tick-size)。 |
| **Token Factory** | 用于无需许可创建代币的原生模块，格式为 `factory/{creator}/{subdenom}`。 |
| **Subaccounts** | 隔离的[交易账户](/cn/developers/concepts/trading-account)，用于保证金和仓位管理，与主钱包分离。 |
