## 分步指南

<img src="/img/bridge-deploy-flow.svg" alt="Bridge and deploy flow: Ethereum to Injective" />

### 1. 通过 Peggy 桥接

使用 Peggy 跨链桥合约将你的 ERC-20 代币从 Ethereum 发送到 Injective。

在 Ethereum 上需要两笔交易：
1. **Approve**：授权 Peggy 合约使用你的代币
2. **sendToInjective**：在 Peggy 合约上调用，传入代币地址、你的 Injective 地址和金额

某个 ERC-20 的首笔跨链桥交易会自动在 Injective 上创建 denom，格式为 `peggy0x{CONTRACT_ADDRESS}`。

<Info>
Peggo 中继器通常在 2 分钟内处理充值。你可以通过 [Injective 测试网浏览器](https://testnet.explorer.injective.network)或 REST API 验证你的余额。
</Info>

完整细节请参阅 [Peggy 跨链桥指南](/cn/developers-native/bridges/ethereum)。

### 2. 创建 MTS 代币对

创建代币对，使你的 Peggy denom 可以从 EVM 侧（MetaMask、Solidity 合约、Blockscout）访问。

```bash
injectived tx erc20 create-token-pair \
  "peggy0xYOUR_TOKEN_ADDRESS" \
  --from=YOUR_KEY \
  --keyring-backend=file \
  --chain-id=injective-888 \
  --node=https://testnet.sentry.tm.injective.network:443 \
  --gas=3000000 \
  --gas-prices=160000000inj \
  --yes
```

<Warning>
**Gas 要求：** 此交易至少需要 `--gas=3000000`。ERC20 模块在内部部署 EVM 合约时使用硬编码的 200 万 gas 上限。任何低于约 210 万的 gas 值都会因 `gas computation overflow/underflow` 错误而失败。
</Warning>

对于 Peggy denom，**任何人**都可以创建代币对——无需管理员。模块会自动部署一个 `FixedSupplyBankERC20` 合约。

交易成功后，查询新的 ERC20 地址：

```bash
curl -s "https://testnet.sentry.lcd.injective.network:443/injective/erc20/v1beta1/all_token_pairs" \
  | jq '.token_pairs[] | select(.bank_denom | contains("YOUR_TOKEN_ADDRESS"))'
```

完整细节请参阅 [ERC20 模块文档](/cn/developers-evm/erc20-module)。

### 3. 设置代币元数据

代币元数据（名称、符号、小数位数）决定了你的代币在 MetaMask、Blockscout 以及任何调用合约 `symbol()`、`name()` 或 `decimals()` 的 EVM 工具中的显示方式。

<Warning>
Peggy 桥接的代币不会自动继承 Ethereum 上的元数据。MTS ERC20 合约从 Injective 的 bank 模块读取元数据。如果未设置 bank 元数据，代币将显示为空白名称、空白符号和 0 位小数。
</Warning>

**对于 Peggy denom（`peggy0x...`）：** 元数据必须通过[治理提案](/cn/developers/testnet-proposals)设置。这是因为 Peggy denom 没有管理员权限——只有治理才能写入 bank 模块的元数据存储。有关完整的提案模板以及如何与团队协调测试网验证者投票，请参阅[代币元数据指南](/cn/developers/assets/token-metadata)。

**对于 TokenFactory denom（`factory/...`）：** denom 管理员可以直接调用 `MsgSetDenomMetadata`。请参阅 [TokenFactory 示例](/cn/developers-native/examples/token-factory)。

**对于 Injective dApp 中的前端显示：** 将你的代币提交到 [injective-lists](https://github.com/InjectiveLabs/injective-lists/blob/master/CONTRIBUTING.md)。这与链上元数据是分开的，不会影响 MetaMask 或 Blockscout。
