x402 是一个开放协议，它借助长期未被使用的 `402 Payment Required` HTTP 状态码，将支付嵌入到 HTTP 请求的生命周期中。在支付可在一个区块内结算（约 650 毫秒）的 Injective EVM 上，x402 可以将任意 API 端点变成按请求付费的服务，无需 API key、订阅或注册。

## 什么是 x402？

x402 将支付嵌入到 HTTP 协议中，
服务器在返回数据之前，会作为 API 响应流程的一部分要求并收取支付。

### 一次 x402 交互中会发生什么？

当客户端调用一个受 x402 保护的 HTTP 端点时，交互过程如下：

1. 客户端向该 API 端点发送一次正常的 HTTP 请求。
2. 服务器返回 `402 Payment Required` 和一份价格报价。
3. 客户端*签署*一笔 USDC 转账交易，但该交易尚未被广播到网络。
4. 一个 x402 *facilitator*（结算方）将已签名的支付提交到区块链并等待确认。
5. 客户端重试原始请求，这次带上已完成支付的详细信息。
6. 服务器通过 facilitator 验证收据，并返回所请求的数据。

![x402 interaction steps](/img/x402-demo-interaction-steps.png)

### x402 免去了哪些步骤？

无需预先注册、API key 管理、订阅或信用卡。
这意味着服务器可以在一次 HTTP 会话中完成报价、验证支付并交付数据。

facilitator 处理所有区块链交互，让你的 API 服务器保持 web 原生形态：

| Facilitator 的职责 | 它帮你屏蔽了什么 |
|---|---|
| 验证支付签名 | 服务器上的加密验证代码 |
| 将交易提交到链上 | RPC 端点管理 |
| Gas 估算与费用 | Gas 计算逻辑 |
| 等待链上确认 | 区块轮询：你只收到一个 yes/no |

### x402 只适用于以太坊吗？

x402 与网络无关：
该开放标准同时支持 EVM 兼容网络、SVM 兼容网络等。
本教程演示如何在 *Injective* 上使用 x402。

### 为什么在 Injective 上使用 x402？

Injective 具有非常高的吞吐量和极低的延迟：
出块时间约为 650 毫秒，
并具备确定性的单区块最终性。
这意味着 x402 支付可以以接近信用卡支付的速度完成结算，
而成本却远远低于信用卡。
这解锁了新的应用场景，包括按次付费和小额支付。
由于 x402 交易也是完全程序化的，
它们非常适合 AI 智能体使用。

## x402 如何实现智能体支付？

x402 让 API 变得可被程序化支付。
当调用方是 AI 智能体而非人类时，
这一特性变得至关重要。

传统的计费模型
（API key、OAuth 流程、按月订阅）
需要人类来设置和维护凭据。
当 AI 智能体自主运行或跨大量用户扩展时，预先注册的凭据会成为瓶颈和安全隐患：
密钥会过期，配额被共享，每接入一个新服务都需要人为参与。

x402 消除了这一瓶颈。
持有 USDC 余额的智能体可以在无需预先注册的情况下调用任何受 x402 保护的端点。
API 报价，智能体签署支付，数据以程序化的方式返回。
这一过程按每次请求执行，链上收据构成不可篡改的审计记录。
个别 API 调用中不需要人类介入。

在 Injective 上，x402 提供了这样的支付原语：
让智能体在运行时获取市场数据、触发交易并调用各类服务。
无需人类提前进行任何设置或操作。

<Info>
x402 标准是开源且与网络无关的。
它由 Coinbase 发起，并对所有网络开放实现。
完整规范请参阅 [x402 协议文档](https://docs.x402.org/introduction)。
</Info>

## 使用 x402 保护你自己的 API 端点

![npm install](/img/x402-demo-npm-install.png)

创建一个带有 x402 保护端点的 Node.js 服务器：

1. 进入你的项目目录（或使用 `npm init -y` 新建一个）。
2. 在终端运行 `npm install @injectivelabs/x402` 安装 x402 库。
3. 创建 `server.js` 并从 `@injectivelabs/x402/middleware` 导入 `express` 和 `injectivePaymentMiddleware`。
4. 在中间件栈中调用 `injectivePaymentMiddleware`，指定要保护的端点、支付网络、USDC 资产地址，以及以最小单位表示的金额。

<Info>
一个最小示例：

```js server.js
import express from 'express';
import { injectivePaymentMiddleware } from '@injectivelabs/x402/middleware';

const app = express();

app.use(
  injectivePaymentMiddleware(
    {
      'GET /perps': {
        accepts: [{
          // Injective EVM (chain ID 1776)
          network: 'eip155:1776',
          // USDC on Injective EVM 
          asset: '0xa00C59fF5a080D2b954d0c75e46E22a0c371235a',
          // $0.01 (USDC uses 6 decimal places)
          amount: '10000',
        }],
      },
    },
    { facilitatorUrl: process.env.X402_FACILITATOR_URL }
  )
);

app.get('/perps', (_req, res) => res.json({ data: "... your data here ..." }));

```

使用了 npm 上的 [`@injectivelabs/x402`](https://www.npmjs.com/package/@injectivelabs/x402)。
</Info>

任何在请求头中携带有效 USDC 支付收据的 HTTP 客户端
（包括 AI 智能体）都能获得响应。
你无需在服务器上实现 API key，甚至无需实现用户账号系统。
