一键将 Injective 添加到浏览器钱包，或使用下方的手动配置。Injective 提供两个可互操作的接口：

- **Injective EVM** 是兼容以太坊的 JSON-RPC 层。可与 MetaMask、Trust Wallet 等 EVM 钱包配合使用。
- **Injective（原生）** 是原生 Cosmos SDK 链。可与 Keplr 配合使用。

<Info>
Injective EVM 与 Injective 原生链映射到同一个网络。它们使用不同的 chain ID，但共享底层状态。完整参考请参见
[Network Information](/cn/developers/network-information) 与
[EVM Network Information](/cn/developers-evm/network-information)。
</Info>

## Injective EVM

Injective EVM 可与 MetaMask、Trust Wallet 等 EVM 钱包配合使用。选择一个网络，然后选择一个钱包选项来添加或切换到 Injective。

            throw error;
          }))
