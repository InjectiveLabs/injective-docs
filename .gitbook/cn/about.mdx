## 什么是 Injective？

Injective 是专为**金融**而生的**区块链**。

## Injective 有何不同？

Injective 提供完全链上的订单簿交易所、
通过频繁批量拍卖（FBA）实现的抗 MEV 交易排序、
与 110+ IBC 网络和 Ethereum 的跨链互操作性、
EVM 智能合约，
以及生成式 AI 和智能代理构建工具。

Injective 是唯一一个让开发者可以使用预构建、可定制的[模块](./developers-native/)来创建动态应用的区块链，这些应用在其他网络上是无法实现的。
结合对其核心架构的优化和增强的跨链互操作性，
Injective 提供了一个高性能网络，
能够高效、安全地将全球金融系统带到链上。

## Injective 的性能如何？

Injective 还具有高度的可扩展性：

  |  |  |
  |---|---|
  | 持续吞吐量 | 25,000 tx/s |
  | 理论吞吐量上限 | 600,000 tx/s |
  | 出块时间 | 650ms |
  | 交易最终性 | 即时，通过定制的 Tendermint（CometBFT） |
  | 标准交易费用 | ~ $0.0003 |
  | 平均交易费用 | &lt; $0.01 |

<Info>
  以上数据截至 2026 年 4 月。
  请注意，这些数据可能会随市场变化和使用情况而改变。
</Info>
