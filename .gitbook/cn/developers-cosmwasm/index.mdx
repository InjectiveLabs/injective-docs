本节面向使用 CosmWasm 在 Injective 上构建的开发者。
CosmWasm 是为 Cosmos 生态系统打造的、基于 WebAssembly 的智能合约平台。
无论你是在编写 Rust 合约、与 Injective 的原生模块集成，还是通过治理部署到主网，
都可以在这里找到覆盖整个 CosmWasm 开发生命周期（从本地开发到生产部署）的完整指南。

Injective 弥合了 WebAssembly 合约与高性能金融基础设施之间的鸿沟，
从而提升了 CosmWasm 开发体验。
与合约孤立运行的标准 CosmWasm 链不同，
Injective 的 `Any` 消息系统支持 Rust 合约与原生模块直接通信，使合约
能够在链上订单簿下单、查询预言机价格馈送、创建 TokenFactory 资产以及参与拍卖。
CW20 Adapter 通过将 CW20 代币转换为原生 denom，进一步扩展了互操作性，
使 CW20 代币可以在 Injective 的交易所上无缝交易。
借助 `injective-test-tube`，开发者可以针对真实的链逻辑（而不是模拟）对合约进行集成测试，
确保其在真实环境中的正确性。结合 Injective 的亚秒级出块时间和无需许可的测试网，
CosmWasm 开发者可以获得一个生产级环境，用于构建充分利用
Injective 金融原语深度的复杂 DeFi 应用。

## 关键概念 {#key-concepts}

| 术语 | 定义 |
|------|------------|
| **CosmWasm** | 为 Cosmos 构建的基于 WebAssembly 的智能合约平台，支持使用 Rust 编写安全、可移植且具有确定性执行的合约。 |
| **CW20 Adapter** | 一个将 CW20 代币转换为原生 TokenFactory denom 的桥接合约，使 CW20 代币能够与 Injective 的交易所和其他原生模块交互。 |
| **Any Messages** | Protobuf 编码的消息（CosmWasm 2.0+），允许 CosmWasm 合约与 Injective 的 exchange、oracle 和 tokenfactory 等原生模块交互。 |
| **injective-test-tube** | 一个集成测试库，在内存中运行真实的 Injective 链逻辑，用于针对真实的模块行为（而非模拟）测试 CosmWasm 合约。 |
| **WASMx** | Injective 管理 CosmWasm 合约部署的模块，包括主网代码上传的治理提案和权限管理。 |
