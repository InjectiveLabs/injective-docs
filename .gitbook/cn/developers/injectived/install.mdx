## 平台兼容性指南

| 平台 | 预构建二进制文件 | Docker |
|----------|-------------------|-------- |
| macOS (M1/ARM) | ❌ | ✅ |
| macOS (Intel) | ❌ | ✅ |
| Windows (x86_64) | ❌ | ✅ |
| Windows (ARM) | ❌ | ✅ |
| Linux (x86_64) | ✅ | ✅ |
| Linux (ARM) | ❌ | ✅ |

## 使用预构建二进制文件入门

Linux x86_64 用户请从 [Injective Foundation Releases](https://github.com/InjectiveFoundation/injective-core/releases) 下载二进制文件。测试网版本带有 `-beta` 标记，目前最新版本为 `v1.21.0-beta.2`。主网即将升级到 `v1.21.0`。如需立即同步，请选择目标网络当前运行的版本，并在解压 `linux-amd64.zip` 前核对校验和。

```bash
unzip linux-amd64.zip
sudo install -m 0755 injectived /usr/bin/injectived
sudo install -m 0644 libwasmvm.x86_64.so /usr/lib/libwasmvm.x86_64.so
sudo ldconfig
injectived version
```

运行 `injectived version` 确认版本与所选发布一致。验证者还需安装匹配版本的 Peggo。

## 使用 Docker 入门

本地开发也可以使用已发布的 Docker 镜像。请选择示例所需的版本标签。

```bash
docker run --rm injectivelabs/injective-core:v1.21.0 injectived version
```
