<Note>
Effective in v1.21.0, Injective removed Coinbase, PriceFeed, and Stork oracle relays and queries. The separate `Provider` oracle type still lets relayers approved through governance publish custom feeds. [Provider Oracle guide](/developers-defi/provider-oracle)
</Note>

The Oracle module verifies and stores external price updates. Native Injective modules read those prices for operations such as valuing derivative positions and determining liquidation eligibility. Each oracle type defines how the module identifies its feeds and verifies updates.

See [Oracle Queries](/developers-native/query-chain/oracle) for reading prices and the [Provider Oracle guide](/developers-defi/provider-oracle) for publishing custom feeds.
